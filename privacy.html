Privacy Policy — Sobat Mood Uploader

Last updated: 29 October 2026

What this app is

Sobat Mood Uploader ("the App") is a private automation tool operated by the owner of the Sobat Mood YouTube channel (https://www.youtube.com/@sobatmood). The App uses the YouTube Data API v3 to upload and manage videos on the owner's own channel only.

Data the App accesses

  • An OAuth 2.0 access token and refresh token for the owner's own Google account, granted by the owner with the youtube.upload scope (upload videos on the owner's behalf).
  • Basic channel information of the owner's own channel (channel ID, title) returned by the API.
  • Video files, titles, descriptions and thumbnails that the owner supplies for upload.

How data is used

The tokens are used only to call the YouTube Data API v3 to upload the owner's videos to the owner's channel and to verify the published result. No data is used for advertising, profiling, or any other purpose.

Storage and sharing

OAuth credentials are stored on the owner's own server in a permission-restricted file (accessible only to the owner). Data is never sold, rented, or shared with third parties. The only external service involved is Google's YouTube Data API v3, governed by the Google Privacy Policy and the YouTube Terms of Service.

Revoking access

The owner can revoke the App's access at any time at https://myaccount.google.com/permissions — revoking stops all API access immediately. Stored credentials can be deleted from the owner's server on request at any time.
